# car-hunter

בוט Python אישי למציאת רכבים בישראל, המיועד לריצה עצמאית ב־GitHub Actions.
אין צורך במחשב מקומי דלוק, סשן דפדפן או CAPTCHA ידני.

## מקור וגבולות המידע

המקור הממומש הוא cars.zehcan.co.il דרך HTTP בלבד. ה־parser נבנה מצילומי
HTML שהתקבלו בהרצת GitHub Actions אמיתית. החילוץ מוגבל למודעה עצמה,
כדי לא לערבב מחירים ותאריכים של מודעות אחרות או כתבות המוטמעות באותו דף.
פוקוס אינו מופעל בשל איסור איסוף אוטומטי בתקנון. במדגם ad נמצאו מודעות
מ־2025. יד2 והומלס אינם מקורות פעילים. ראו [דוח המקורות](SOURCE_REPORT.md).

תאריך הפרסום ב־Zehcan הוא התאריך המוצהר באתר; דיוקו לא אומת מול המוכר.
אין תאריך עדכון מאומת. קילומטראז׳, גיר, מנוע, גרסה וסוג מוכר אינם שדות
מובנים באתר; פירוט מפורש בתיאור המוכר נשלף כטענה שלו, וחוסרים נשארים חסרים.
לדוגמה: "לא סוחר" מסומן כמוכר פרטי מוצהר, "גיר ידני" נשמר כידני,
וטווח נסיעה של רכב חשמלי אינו קילומטראז׳. מיקום נשלף רק מביטוי שנבדק בתיאור.
אין להסיק סוג מוכר משם המפרסם או מבעלות הרכב.
טלפון גלוי נשמר ונכלל בהודעה האישית; אינו מודפס בלוגים או מועבר כשדה קשר ל־DeepSeek.

לא נמצא קישור לתנאי שימוש ב־Zehcan. robots.txt מחזיר HTML במקום כללים
שימושיים; זה אינו היתר מפורש. האיסוף אישי ומוגבל, עם לפחות שתי שניות
בין בקשות. כללי robots מכובדים אם מופיעים, ושגיאות גישה מדווחות.
אין עקיפת חסימות או שימוש בסשן ידני.

## מסלול הריצה

HTTP → מודעה אחידה → Neon/psycopg → DeepSeek → טלגרם.
המפתח (source, ad_id) מונע רשומות כפולות. הרצה חוזרת מעדכנת את המודעה
ושומרת first_seen ומצב התראות. דירוג ממוחזר כשהקלט והפרופיל לא השתנו.
כשל בדירוג אינו מוחק מודעה שכבר נשמרה וניתן לנסות שוב בהרצה הבאה.
פרטי מודעה בודדת שנכשלים אינם מונעים את עיבוד המודעות האחרות; הריצה מסומנת ככישלון חלקי.

DeepSeek מעריך התאמה מתוך עובדות מפורשות בלבד, עם deepseek-flash.
הוא אינו מקור לעובדות על אמינות, ביצועים, צריכת דלק או מידות של גרסה.
טענות מוכר לא אומתו. ציון AI אינו מאשר גיר או גודל שחסרים במודעה.
כדי למנוע המצאת עובדות, המודל בוחר הסברים ושאלות מרשימה של עובדות/חוסרים
שנגזרה בקוד מתוך המודעה; הסבר עם מזהה שאינו ברשימה נדחה. אין ניסוח עובדתי חופשי מהמודל.

התראות רגילות דורשות גיר אוטומטי מפורש, מעמד candidate וציון 60 ומעלה.
סוכנות דורשת ציון 85 ומעלה. אלו ספי התראות פנימיים, לא תקרת מחיר או ק״מ.
במודעות שנאספו לא הופיע גיר אוטומטי מפורש, ולכן אינן נשלחות כהמלצות רגילות.
דגל ההדגמה שולח מודעה אמיתית אחת עם אזהרת חוסרים;
סימון ההדגמה נשמר ב־Neon כדי למנוע חזרה בהרצות הבאות.

פרופיל החיפוש ב־search_profile.json: יעד 50,000 ש״ח, ללא תקרת חריגה מוסכמת,
אוטומט בלבד, העדפה ל־2017+, ק״מ נמוך, מוכר פרטי ובאר שבע/דרום.
מחיר הוא מחיר רכישה מלא בלבד; תשלום חודשי אינו מחיר רכישה.

## GitHub Actions

Secrets נדרשים: DATABASE_URL, DEEPSEEK_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID.
Car hunter scan רץ על Ubuntu של GitHub. concurrency עם cancel-in-progress: false
מונע workflows חופפים. נעילת Postgres נוספת מגינה על השמירה/דירוג/התראות.
התזמון הוא כל שעתיים, בדקה 17 לפי UTC; GitHub עשוי לעכב ריצה מתוזמנת.
Source audit הוא כלי בדיקה נפרד ללא Secrets וללא תזמון שוטף.

מועד איסוף נשמר ב־first_seen/last_seen ואינו תאריך פרסום או עדכון.
ראו [תוצאות אימות](VERIFICATION.md) לקישורי הריצות ולסטטוס התזמון.

## פיתוח מקומי — אופציונלי

Python 3.12 ומעלה:

```powershell
uv sync --frozen
uv run python -m unittest discover -s tests -v
uv run python -m car_hunter check
uv run python -m car_hunter scan --source zehcan --limit 9 --analyze
uv run python -m car_hunter scan --analyze --notify
uv run python -m car_hunter stats
```

חלופה: python -m venv .venv ולאחר מכן pip install -e . דרך Python של ה־venv.
אם אין .env, העתיקו .env.example ומלאו ערכים. אין לדרוס קובץ קיים.
משתני סביבה מקבלים קדימות. .env ו־artifacts מוחרגים מ־Git.

check --telegram-test שולח הודעת חיבור בכל הרצה; אינו נחוץ להפעלה שוטפת.
scan --analyze --demo-notification שולח הדגמה חד־פעמית, אם טרם נשלחה.
ingest זמין ליבוא מערך JSON שכבר נורמל ואומת; אינו חלק מהאוטומציה.
שדות חסרים נשארים null; published_at ו־updated_at הם תאריכי ISO או null.
אין צורך ב־Node.js, Neon CLI, Docker או שרת.
